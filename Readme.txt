# Gestionnaire de Contacts

## Objectif
Cette application C++ permet de gérer efficacement une liste de contacts. Les utilisateurs peuvent ajouter, afficher, rechercher, modifier, et supprimer des contacts. 
Les données sont sauvegardées dans un fichier texte pour une persistance des données entre les sessions.

## Étapes pour compiler et exécuter
1. **Compiler le projet :**
   Ouvrez un terminal dans le répertoire contenant les fichiers et exécutez la commande suivante :
   g++ -o gestionnaire_contacts main.cpp
Et ensuite la commande .\gestionnaire_contacts.exe pour exécuter le code.
